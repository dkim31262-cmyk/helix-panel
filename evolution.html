Preserve the existing contract

helix.bridge.v1 configures each runtime. helix.result.v1 returns a single post-fold envelope. A huddle uses orchestration_graph = chain, while skill_graph keeps its own meaning. This HUD does not rewrite those schemas.

What live multi-provider orchestration still needs

Server-side provider keys, explicit permissions, a Relay service, billing and quota controls, audit receipts, test fixtures, and browser/mobile verification. These do not exist merely because a static page recommends a route.
